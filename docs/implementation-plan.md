# План реализации проекта «Чичик»

Документ опирается на `docs/architecture.md` и решения по продукту (роли, админка, питомец, 4 предмета).

**Решения, зафиксированные перед стартом MVP**

| # | Решение |
|---|---------|
| Админы | Несколько редакторов; назначение через `ADMIN_EMAILS` |
| Админка правит | Предметы, темы, задания, пробники, тексты лендинга |
| Публикация | Без черновиков: сохранил = видно ученику |
| Предметы MVP | Русский, математика (база), обществознание, химия |
| Питомец | Оставляем как UI-фичу; не учебный предмет |
| Контент старт | Минимальный seed + админка параллельно (этап 1b) |

---

## 1. Цель MVP

Сделать рабочее веб-приложение, в котором:

**Ученик**

1. Регистрируется и входит
2. Подключает профили ОГЭ и ЕГЭ
3. Изучает теорию и практику по 5 темам каждого из 4 предметов
4. Проходит диагностику и видит слабые темы
5. Повторяет ошибки в банке ошибок
6. Проходит ≥1 пробник на предмет
7. Пользуется питомцем Чичик (картинка, чирики, магазин)

**Админ**

8. Входит с ролью `admin` и управляет предметами, темами, заданиями, пробниками и текстами лендинга

**Definition of Done:** пункты выше работают на Vercel + Supabase Free с прототипным контентом (seed + правки из админки).

---

## 2. Объём контента MVP

| Предмет | Тем | Заданий на тему | Пробников |
|---------|-----|-----------------|-----------|
| Русский язык | 5 | 5–8 | ≥1 |
| Математика (база) | 5 | 5–8 | ≥1 |
| Обществознание | 5 | 5–8 | ≥1 |
| Химия | 5 | 5–8 | ≥1 |

Биология и география из текущего UI-мока **не входят** в учебный MVP (убрать из каталога при подключении БД или скрыть).

### Черновой список тем (для seed)

**Русский:** орфограммы в корне; Н/НН; пунктуация; лексика; работа с текстом (без автопроверки эссе).

**Математика (база):** дроби и проценты; линейные уравнения; простейшая геометрия; функции/графики (база); текстовые задачи / вероятность.

**Обществознание:** человек и общество; экономика; право; политика; социальная сфера.

**Химия:** атом; связи; классы соединений; расчёты; реакции и коэффициенты.

### Этап 1 — Auth, каркас, роли (1–2 дня)

**Задачи**

## 4. Порядок работ

```text
0. Supabase + env
     →
1. Auth + roles + onboarding + shell
     →
1b. Admin CRUD + минимальный seed   ⎤ можно частично
2. Практика ученика из БД           ⎦ параллельно
     →
3. Диагностика
     →
4. Банк ошибок
     →
5. Пробники
     →
6. Полировка + деплой
```

Зависимости:

- 1b нужен до полного наполнения контента руками
- 2 требует таблицы контента и хотя бы seed/админ-данные
- 3–5 требуют стабильных `tasks` + `attempts`

## 5. Чеклист приёмки MVP

### Auth и роли

- [ ] Регистрация и вход
- [ ] Без входа `/app` недоступен
- [ ] Email из `ADMIN_EMAILS` → доступ в `/admin`
- [ ] Обычный ученик в `/admin` получает отказ
- [ ] ОГЭ и ЕГЭ + предметы сохраняются

### Контент и админка

- [ ] 4 предмета у ученика
- [ ] Админ создаёт/правит тему, задание, пробник, текст лендинга
- [ ] После сохранения ученик видит новое сразу
- [ ] 5 тем × 5–8 заданий (наполнено seed и/или админкой)
- [ ] ≥1 пробник на предмет

### Учёба

- [ ] Диагностика → карта слабых тем
- [ ] Ошибка → банк ошибок → resolved
- [ ] Пробник: таймер + разбор
- [ ] Mastery сохраняется после перезахода

### Питомец

- [ ] `/app/pet` и магазин работают (localStorage)
- [ ] Не ломают учебные сценарии

### Нефункциональное

- [ ] Mobile у ученика
- [ ] Секреты не в git
- [ ] Задеплоено на free-хостинге
